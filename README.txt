MEU ESPAÇO — SITE BÁSICO

ARQUIVOS
index.html: conteúdo da página.
style.css: cores, fontes e layout.
script.js: botão de tema e ano do rodapé.
assets/favicon.svg: ícone da aba do navegador.

COMO TESTAR
Extraia o ZIP e abra index.html no navegador. Mantenha os arquivos juntos.
Não é necessário instalar nada, rodar npm ou compilar.

COMO PERSONALIZAR
Abra index.html em um editor de texto e altere os títulos, textos e projetos.
Os três projetos são exemplos, não projetos reais publicados.
Em style.css, altere as cores nas variáveis do início do arquivo.

PUBLICAÇÃO
Envie o conteúdo desta pasta para a raiz do repositório, mantendo index.html
na raiz e a pasta assets junto dele. Não envie apenas o ZIP.
Configure a hospedagem do GitHub Pages para usar a pasta que contém index.html.
Todos os caminhos são relativos, inclusive para repositórios com subpasta na URL.
